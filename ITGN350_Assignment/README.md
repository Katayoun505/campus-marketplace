# Campus Marketplace
A Smarter Way to Buy and Sell on Campus

## Overview
Campus Marketplace is a web application that allows students to buy and sell products within their university community.

## Features
- User Signup and Login
- Password hashing using SHA256
- Session-based authentication
- Product listing and browsing
- Category filtering and search
- Sell product functionality
- Contact form with database storage

## Technologies Used
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server (LocalDB)
- HTML, CSS, Bootstrap
- JavaScript

## How to Run
1. Open project in Visual Studio
2. Run:
   Update-Database
3. Press F5 to run the app
