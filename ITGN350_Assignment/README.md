# 🛒 Campus Marketplace  
### 🎓 A Smart Way to Buy and Sell on Campus  

---

## 📌 Overview  
Campus Marketplace is a full-stack web application developed using ASP.NET Core MVC that enables university students to buy and sell products within their campus community.  

The platform provides a secure, user-friendly, and efficient environment for peer-to-peer transactions.

---

## 🚀 Features  

### 🔐 Authentication & Security  
- User Signup and Login  
- Password hashing using SHA256  
- Session-based authentication  

### 🛍️ Product Management  
- Browse products  
- Search functionality  
- Category filtering  
- Product details page  

### 📤 Sell Feature  
- Add new product listings  
- Store product data in database  

### 📩 Contact System  
- Contact form  
- Messages stored in database  

### 🎨 User Interface  
- Responsive design using Bootstrap  
- Clean and modern layout  
- Interactive product cards  

---

## 🛠️ Technologies Used  
- ASP.NET Core MVC  
- C#  
- Entity Framework Core  
- SQL Server (LocalDB)  
- HTML5, CSS3, Bootstrap  
- JavaScript  

---

## ⚙️ How to Run the Project  

1. Open the project in Visual Studio  
2. Open **Package Manager Console**  
3. Run:  
   ```bash
   Update-Database
   ```
4. Press **F5** to run the application
